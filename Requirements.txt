# Reproducible PATE Privacy Accounting for IoT Intrusion Detection

## Abstract
This notebook presents a rigorous and reproducible reference implementation of the legacy Laplace Report NoisyMax PATE (Private Aggregation of Teacher Ensembles) accounting mechanism for tabular IoT intrusion detection. The experiment explores various teacher and student architectural configurations and performs a sensitivity analysis on the number of teachers, evaluating their impact on privacy guarantees (data-dependent and data-independent epsilon) and student model accuracy.

## 1. Introduction
This document serves as a guide to replicate the PATE privacy accounting experiment, ensuring methodological rigor and transparency for academic scrutiny, particularly for submissions to journals like Springer. It details the experimental setup, data handling, model training, privacy accounting, and result analysis steps.

It is highly recommended to use a virtual environment to manage dependencies for your project. This prevents conflicts with other Python projects on your system.

1.  **Create a virtual environment** (e.g., named `pate_env`):

    ```bash
    python -m venv pate_env
    ```

    *   On macOS/Linux:

        ```bash
        source pate_env/bin/activate
        ```

    *   On Windows:

        ```bash
        .\pate_env\Scripts\activate
        ```

3.  **Install dependencies**: With your virtual environment activated, install all required libraries using the `requirements.txt` file:

    ```bash
    pip install -r requirements.txt
    ```
